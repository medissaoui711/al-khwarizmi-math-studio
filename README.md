## 🚀 About The Project

**Al-Khwarizmi Math Studio** is an advanced, Arabic-first mathematical modeling and tutoring environment. It leverages the power of Google's Gemini AI to provide step-by-step problem solving, detailed explanations in Arabic, and dynamic function plotting.

### ✨ Key Features
*   **AI-Powered Tutor:** Solves complex math problems with step-by-step explanations using Gemini 2.5 Flash.
*   **Dynamic Plotting:** Instantly visualizes mathematical functions using interactive charts.
*   **LaTeX Rendering:** Beautifully renders complex mathematical notations.
*   **Arabic First:** Fully optimized RTL interface and Arabic natural language processing.
*   **Responsive Design:** Modern UI built with Tailwind CSS that works on all devices.

## 🛠️ Tech Stack | التقنيات المستخدمة

*   **Frontend Framework:** [React 19](https://react.dev/)

*   **Math Rendering:** [KaTeX](https://katex.org/)
*   **Charting:** [Recharts](https://recharts.org/)
*   **Icons:** [Lucide React](https://lucide.dev/)

## ⚙️ Installation & Setup | التثبيت والإعداد

Follow these steps to get a local copy up and running.
اتبع الخطوات التالية لتشغيل النسخة المحلية.

### Prerequisites | المتطلبات
*   Node.js (v18 or higher)
*   Google Gemini API Key ([Get it here](https://aistudio.google.com/))

### Steps | الخطوات

1.  **Clone the repository | استنسخ المستودع**
    ```bash
    git clone https://github.com/yourusername/al-khwarizmi-math-studio.git
    cd al-khwarizmi-math-studio
    ```

2.  **Install dependencies | ثبت الحزم**
    ```bash
    npm install
    ```

3.  **Configure Environment | إعداد المتغيرات**
    Create a `.env` file in the root directory and add your API Key:
    قم إنشاء ملف `.env` وأضف مفتاح API الخاص بك:
    ```env
    API_KEY=your_google_gemini_api_key_here
    ```

4.  **Run the application | شغل التطبيق**
    ```bash
    npm start
    ```
